## 같은 Google 계정을 쓸 때의 공유 위험 (문서화 요구 사항)
- Apps Script 할당량(일일 실행 시간, 동시 실행, 트리거 수, 메일 등)은 **계정 단위**로 함께 씀 → 게임 트래픽이 많아지면 잠만보 스크립트에도 영향 가능
- 계정 정지·비밀번호 분실 같은 계정 장애가 두 서비스에 동시에 영향
- 권장: 운영(prod)은 **새 Google 계정**이 시트·GAS 를 소유. 스테이징은 기존 계정이어도 됨
- GitHub 도 같은 계정이면 Actions 사용량·Pages 를 같이 씀(공개 저장소는 대부분 무료 범위 — 최신 정책은 출시 전 확인 필요)
- 완전한 출처 분리가 필요하면: 별도 GitHub 조직/계정(다른 `*.github.io`), 또는 사용자 지정 도메인

## 환경 표

| 환경 | 프론트 | API | 데이터 | 저장 키 |
|---|---|---|---|---|

| staging | /monster-grow/staging/ | 몬스터키우기_staging 의 웹 앱 | 스테이징 시트 | `mkg_staging_` |
| prod | /monster-grow/ | 몬스터키우기_prod 의 웹 앱 | 운영 시트 | `mkg_prod_` |
