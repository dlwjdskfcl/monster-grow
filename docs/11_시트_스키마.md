# 11. Google Sheets 스키마 (신규 문서 전용)

`Setup.gs` 의 `setup()` 이 탭·제목을 만듦. 열은 이 순서로 고정(코드가 열 번호로 읽음).

| 탭 | 열 | 정본? | 쓰는 곳 |
|---|---|---|---|
| Players | playerId · createdAt · updatedAt · schemaVersion · lastSeenAt · recoveryHash · status | O | 가입, 명령마다 updatedAt |
| PlayerState | playerId · stateJson · stateHash · revision · updatedAt | **O (정본)** | 명령마다 한 행 |
| Inventory | playerId · itemId · amount · revision · updatedAt | 사본 | `refreshMirrors()` 1시간 |
| Collection | playerId · creatureId · level · resonance · traitsJson · updatedAt | 사본 | `refreshMirrors()` |
| CommandJournal | requestId · playerId · action · status · resultHash · createdAt | 기록 | 명령마다 추가 |
| GameConfig | configVersion · key · value · enabled(Y) · updatedAt | O | 운영 |
| Announcements | id · title · body · startAt · endAt · enabled(Y) | O | 운영 |
| AdminAudit | requestId · adminId · action · result · createdAt | 기록 | 운영 API·편집기 함수 |
| Migrations | schemaVersion · migrationName · status · executedAt | 기록 | `runMigrations()` |
| Metrics | hour · requests · avgMs · maxMs · ok · duplicate · conflict · rateLimited · serverError · lockFail · invalid · authRequired | 기록 | `flushMetrics()` 1시간 |

## 규칙
- **기본키**: playerId(UUID). Players 와 PlayerState 는 같은 playerId 가 **같은 행 번호** (가입 때 동시에 만듦)
- **행 찾기**: 캐시(6시간)의 행 번호 → 그 행 A열이 playerId 와 같은지 확인 → 다르면 A열에서 TextFinder 정확 일치 (전체 데이터 읽기 아님)
- **큰 수**: stateJson 안에서 문자열 `"가수e지수"`. stateJson·ID 열은 텍스트 서식('@') → 시트가 숫자·날짜로 바꾸지 않음
- **stateHash**: SHA-256 앞 16자. 손으로 고친 행은 경고 로그(값은 그대로 읽음)
- **셀 한도**: stateJson 45,000자 넘으면 저장 거부(STATE_TOO_LARGE). 지금 상태 ≈ 2~3KB
- **행 삭제 금지**: 행 번호가 짝으로 묶여 있음. 탈퇴·정지는 Players.status 를 `banned`/`deleted` 로 (MVP 는 status 를 아직 읽지 않음 — 미구현)
- **GameConfig 키**: offlineCapHours(1~48) · prodMult(0.1~10) · maxTeam(3~5) · minTeamForBoss · rebuildMinDepth · maintenance(Y/N) · maintenanceMessage · readOnly(Y/N) · minClientVersion · rateLimitPerMin. 범위 밖 값은 잘라냄, 60초 캐시
- **규모 추정**: 플레이어 1명 = 2행(Players·PlayerState) + 명령마다 Journal 1행. 시트 한 파일 1,000만 셀 한도 → Journal 은 정기적으로 백업 후 비우기(운영 할 일)
