# 14. 자산 출처 · 권리 검토 목록

## 원칙
- 모든 그림은 이 저장소의 코드(`frontend/src/components/art.ts`)가 그리는 SVG. 외부 이미지·아이콘 세트·글꼴·소리 **없음** (글꼴은 기기 기본 글꼴)
- 기존 게임의 캐릭터·이름·실루엣·배색·UI 배치·설명문·공식·스토리를 참고하거나 변형하지 않음. 장르 요소(자동 전투·성장·초기화 후 영구 성장)만 공유
- 사용하지 않는 표현: 특정 브랜드명, '도감'처럼 특정 IP 를 연상시키는 핵심 용어 대신 '생태 도감', 포획 도구 대신 '공명 계약', '체육관'·'진화' 같은 표현 없음
- **독자 제작이라고 해서 법적 위험이 자동으로 없어지는 것은 아님** → 출시 전 사람의 검토 필요
