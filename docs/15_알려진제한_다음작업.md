## 알려진 제한
1. 모든 쓰기가 스크립트 잠금 하나를 거침 → 동시 사용자가 많으면 대기·BUSY 증가 (부하 테스트로 상한 확인 필요)
2. 3일 이후 성장 둔화 — 후반 지역·씨앗 사용처 추가 필요 (밸런스 표)
3. 정산 한도(기본 8시간)는 접속 중에도 적용 → 클라이언트가 10분마다 자동 저장. 탭이 백그라운드면 건너뜀 → 돌아오면 sync
4. 클라이언트 '보기'와 서버 결과가 아주 조금 다를 수 있음(서버 시각 차이) → 서버 응답으로 교체
5. 토큰 개별 폐기 없음, Players.status(정지) 미사용
6. 서비스 워커 없음 → 오프라인에서는 첫 화면이 뜨지 않음(캐시된 상태는 브라우저 캐시에 의존)
7. 복구 코드 외 계정 연동 없음 (구글·카카오 연동은 다음 단계 — 기존 jammanbo 카카오 앱은 재사용하지 않음)
8. 소리 없음, 다국어 없음
